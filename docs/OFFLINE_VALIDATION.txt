# Offline validation

```
PASS: 42 YAML files, shell syntax and Python compilation
PASS: 8 active YAML templates render with the repo group_vars
PASS: Gateway LoadBalancer allocates no NodePorts
PASS: Gateway Service type is LoadBalancer
PASS: 7 Grafana dashboards, 59 panels (JSON/UID/reference checks)
PASS: resource preservation, selector injection, readiness and NodePort removal fixtures
PASS: tracked secret files are absent
```

Run it with:

```bash
python3 tests/static_validate.py
```

What it covers: YAML/shell/Python syntax, rendering of every active Jinja
template with the repo's real `group_vars`, the Gateway having no NodePorts, the
dashboard JSON (uids, panel ids, datasource uids, non-empty targets), the
upstream renderer preserving resources (including *absence* of resources),
NodePort removal, and the absence of tracked credentials.

What it does **not** cover (see docs/VALIDATION.md): Helm chart validity, image
availability, CRD compatibility, Ansible collection resolution against a real
inventory, and anything requiring a live cluster.
